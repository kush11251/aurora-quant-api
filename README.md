# Aurora Quant API
## Overview
Aurora Quant API is a high-performance trading platform designed for real-time market analysis. It provides a scalable and efficient solution for trading firms and financial institutions.
## Requirements
- Node.js 18 or higher
- npm 8 or higher
## Installation
1. Clone the repository
2. Run `npm install` to install dependencies
3. Run `node src/index.js` to start the server
